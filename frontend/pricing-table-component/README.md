# 💰 Pricing Table Component

A reusable, responsive pricing table component built with **TypeScript** and **CSS Grid**.

## 🎯 Problem

Most SaaS websites need a clean pricing section. This component provides a ready-to-use, customizable pricing table with toggle between monthly/yearly billing.

## ✨ Features

- 🔄 Monthly / Yearly toggle with discount badge
- 📱 Fully responsive (mobile-first)
- 🎨 Highlight "popular" plan
- ♿ Accessible markup (semantic HTML + ARIA)
- 🧩 TypeScript for type safety
- 🚀 Zero dependencies

## 🛠️ Tech Stack

- HTML5 (semantic)
- CSS3 (Grid + Custom Properties)
- TypeScript

## 🚀 Getting Started

1. Open `index.html` in your browser
2. Or serve locally: `npx serve .`
