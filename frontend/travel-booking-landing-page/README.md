# ✈️ WanderVoyage — Travel Booking Landing Page

Modern travel booking landing page with destination search, interactive gallery, pricing cards, testimonials carousel & booking form.

## ✨ Features
- Hero Section with animated search bar
- Popular Destinations with filtering
- Travel Packages pricing
- Testimonials Carousel
- Booking Form with validation
- Stats Counter animations
- Image Gallery
- Fully Responsive

## 🛠️ Technologies
- HTML5, CSS3, Tailwind CSS (CDN), JavaScript
