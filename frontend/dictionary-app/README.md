# WordWise — Dictionary App

> قاموس إنجليزي تفاعلي يساعدك تبحث عن أي كلمة وتعرف معناها، نطقها، ومرادفاتها — بواجهة بسيطة وسريعة.

## 🧩 المشكلة
القواميس التقليدية غير مريحة: واجهات مزدحمة، إعلانات، ولا تعطي معلومات منظّمة (تعريف + مثال + نطق + مرادفات) في مكان واحد.

## ✨ المزايا
- 🔍 **بحث فوري** عن أي كلمة إنجليزية مع Enter أو ضغطة زر.
- 🔊 **استماع للنطق** الأصلي للكلمة مباشرة من الـ API.
- 📖 **تعريفات متعددة** مصنّفة حسب نوع الكلمة (noun, verb, adjective…).
- 💡 **أمثلة استخدام** واقعية لكل تعريف.
- 🔁 **مرادفات ومتضادات** قابلة للضغط للبحث المتسلسل.
- 🌓 **وضع داكن/فاتح** مع حفظ التفضيل.
- 📚 **سجل بحث محلي** بآخر 10 كلمات بحثت عنها.
- 📱 **تصميم متجاوب** يعمل على كل الأحجام.

## 🧰 التقنيات
- HTML5 + CSS3 + JavaScript (Vanilla)
- Tailwind CSS (CDN)
- [Free Dictionary API](https://dictionaryapi.dev/) — REST
- LocalStorage لحفظ السجل والثيم

## 🚀 التشغيل المحلي
```bash
# من جذر الـ repo
npx serve .
# ثم افتح: http://localhost:3000/frontend/dictionary-app/
```
أو افتح `index.html` مباشرة في المتصفح.
