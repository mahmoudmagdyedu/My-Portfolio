# Password Generator App

مولّد كلمات مرور قوية وآمنة، مبني بـ **TypeScript** و HTML/CSS بدون أي اعتماديات خارجية.

## 🧩 المشكلة
كثير من المستخدمين يختارون كلمات مرور ضعيفة أو يعيدون استخدامها عبر مواقع مختلفة، مما يعرّض حساباتهم للاختراق. التطبيق يحل هذه المشكلة بتوليد كلمات مرور قوية وعشوائية فورياً مع تحكم كامل في المعايير.

## ✨ المزايا
- توليد كلمة مرور بطول قابل للتخصيص (4 → 64 حرف).
- خيارات مرنة: أحرف كبيرة، أحرف صغيرة، أرقام، رموز.
- مؤشر قوة كلمة المرور (ضعيفة / متوسطة / قوية / قوية جداً) بناءً على entropy.
- نسخ الكلمة إلى الحافظة بضغطة واحدة (Clipboard API).
- توليد عدة كلمات مرور دفعة واحدة.
- واجهة Responsive وتصميم بسيط وحديث.
- استخدام `crypto.getRandomValues` لعشوائية آمنة بدلاً من `Math.random`.

## 🛠️ التقنيات
- TypeScript
- HTML5 / CSS3
- Web Crypto API
- Clipboard API

## 🚀 خطوات التشغيل المحلي
```bash
# الانتقال إلى مجلد المشروع
cd frontend/password-generator-app

# تثبيت TypeScript عالمياً (لو لم يكن مثبتاً)
npm install -g typescript

# ترجمة TypeScript إلى JavaScript
tsc main.ts

# فتح index.html في المتصفح مباشرة
# أو عبر Live Server في VS Code
```
