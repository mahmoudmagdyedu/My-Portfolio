# ResumeForge — Resume Builder App 📝

> منشئ سيرة ذاتية احترافي مع معاينة لحظية، حفظ تلقائي، وتصدير PDF.

🌐 **عرض مباشر:** [mahmoudmagdy.page/frontend/resume-builder-app/](https://mahmoudmagdy.page/frontend/resume-builder-app/)

---

## 🎯 المشكلة
يحتاج الكثيرون لإنشاء سيرة ذاتية مرتّبة وسريعة بدون اشتراكات أو حسابات. أغلب المنصات الشهيرة تتطلب تسجيلاً أو دفعاً لتصدير ملف PDF نظيف.

## ✨ المزايا
- نموذج شامل: المعلومات الشخصية، الملخّص، الخبرات، التعليم، المهارات، والروابط.
- **معاينة فورية** بجانب النموذج تتحدّث مع كل ضغطة زر.
- **حفظ تلقائي محلي** عبر LocalStorage حتى لو أُغلِقت الصفحة.
- **تصدير PDF** بضغطة واحدة عبر `window.print()` بنمط طباعة محسّن (A4).
- **وضع داكن** مع تخزين التفضيل.
- تصميم متجاوب RTL يعمل على الجوال والتابلت والديسكتوب.

## 🛠️ التقنيات
- **HTML5** — بنية دلالية واضحة.
- **Tailwind CSS** (CDN) — تصميم سريع ومتجاوب.
- **JavaScript (Vanilla)** — منطق التحديث الفوري والحفظ المحلي.
- **CSS Print Styles** — تنسيق صفحة الطباعة.

## 🚀 التشغيل المحلي
لا يحتاج المشروع إلى أي build أو dependencies:

- افتح `index.html` مباشرة في المتصفح.
- أو شغّل سيرفر بسيط: `npx serve .`
