# 📚 EduVerse — E-Learning Platform Landing Page

Modern e-learning platform landing page with course filtering, FAQ accordion, animated counters & responsive design.

## ✨ Features
- Course Category Tabs (Frontend / Backend / Mobile / Data)
- Animated Counters for statistics
- FAQ Accordion
- Testimonials section
- Pricing Plans
- Fully Responsive

## 🛠️ Technologies
- HTML5, CSS3, Tailwind CSS (CDN), JavaScript
