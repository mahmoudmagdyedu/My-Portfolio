# Invoice Generator App

تطبيق ويب بسيط لإنشاء فواتير احترافية بسرعة: إضافة بنود، حساب الإجمالي والضريبة والخصم تلقائياً، ثم طباعتها أو حفظها كـ PDF من المتصفح.

## 🧩 المشكلة
كثير من أصحاب المشاريع الصغيرة والفريلانسرز يحتاجون أداة سريعة ومجانية لإصدار فواتير منسّقة دون الاشتراك في خدمات مدفوعة.

## ✨ المزايا
- نموذج لإدخال بيانات البائع والعميل.
- إضافة/حذف بنود (الوصف، الكمية، السعر).
- حساب تلقائي للمجموع الفرعي، الضريبة (قابلة للتعديل)، الخصم، والإجمالي.
- اختيار العملة وتاريخ الإصدار وتاريخ الاستحقاق.
- معاينة مباشرة للفاتورة جاهزة للطباعة (Print-friendly).
- تصميم Responsive يعمل على الموبايل والديسكتوب.

## 🛠️ التقنيات
- HTML5
- CSS3 (Flexbox/Grid + `@media print`)
- JavaScript (Vanilla)

## ▶️ خطوات التشغيل المحلي
```bash
# من جذر الـ Monorepo
cd frontend/invoice-generator-app
# افتح الملف مباشرة في المتصفح
start index.html      # Windows
open index.html       # macOS
xdg-open index.html   # Linux
```
أو شغّل سيرفر محلي بسيط:
```bash
npx serve .
```
