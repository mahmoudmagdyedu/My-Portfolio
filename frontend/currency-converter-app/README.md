# 💱 Currency Converter App

A real-time currency converter built with **TypeScript**, featuring live exchange rates, multi-currency support, and a sleek responsive UI.

## 🎯 Problem

Quickly converting between currencies requires reliable, up-to-date exchange rates presented in a clean, easy-to-use interface.

## ✨ Features

- 🔄 Real-time exchange rates via free API
- 🌍 Support for 30+ world currencies
- 🔀 Swap currencies with one click
- 📊 Conversion history (session-based)
- 📱 Fully responsive design
- ⌨️ TypeScript for type-safe development
- 🎨 Modern glassmorphism UI with smooth animations

## 🛠️ Technologies

- **TypeScript** — type-safe logic & interfaces
- **HTML5** — semantic markup
- **CSS3** — glassmorphism, animations, responsive grid
- **ExchangeRate-API** — free currency exchange data

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
   cd My-Portfolio/frontend/currency-converter-app
   ```
2. Open `index.html` in your browser, or use a local server.
3. To modify TypeScript, install dependencies and compile:
   ```bash
   npx tsc app.ts --outFile app.js --target ES2020 --module ES2020
   ```
