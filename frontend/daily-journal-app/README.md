# JournalFlow — Daily Journal App 📓

تطبيق يوميات شخصي يجمع بين جمال التصميم وقوة التتبع. سجّل أفكارك، حالتك المزاجية، وتاجاتك يوميًا، وتصفح أرشيفك بسهولة من أي جهاز.

## 🎯 المشكلة
كثيرون يفضّلون كتابة يوميّاتهم لكنهم يحتاجون أداة بسيطة وآمنة تحفظ البيانات محليًا دون تسجيل دخول، مع إمكانية البحث والتصفية لاحقًا.

## ✨ المزايا
- إنشاء وتحرير وحذف تدوينات يومية (CRUD كامل).
- اختيار حالة مزاجية لكل تدوينة (😊 سعيد، 😐 محايد، 😢 حزين، ⚡ نشيط، 🧘 هادئ).
- نظام تاجات (Tags) لتصنيف التدوينات.
- بحث فوري داخل العنوان والمحتوى والتاجات.
- تصدير واستيراد البيانات كملف JSON.
- تخزين محلي عبر LocalStorage — البيانات تبقى عندك.
- وضع داكن / فاتح.
- واجهة عربية RTL متجاوبة بالكامل.

## 🛠 التقنيات
- HTML5
- Tailwind CSS (CDN)
- TypeScript / Vanilla JS (مضمّن)
- LocalStorage API
- File API (للتصدير/الاستيراد)

## 🚀 خطوات التشغيل المحلي
1. استنسخ الـ Monorepo:
   ```bash
   git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
   ```
2. ادخل المجلد:
   ```bash
   cd My-Portfolio/frontend/daily-journal-app
   ```
3. افتح `index.html` بأي متصفح حديث، أو شغّل سيرفر بسيط:
   ```bash
   npx serve .
   ```
