# JSONCraft — JSON Formatter & Validator

أداة احترافية لتنسيق والتحقق من صحة بيانات JSON مباشرة من المتصفح، بدون أي اعتماد على خوادم خارجية. كل المعالجة تتم محلياً في جهازك.

## 🎯 المشكلة
المطورون يتعاملون يومياً مع استجابات API مضغوطة أو غير منسقة، ويحتاجون إلى أداة سريعة لـ:
- تنسيق JSON وقراءته بسهولة.
- التحقق من صحة البنية وتحديد أماكن الأخطاء.
- ضغط JSON لتقليل حجمه قبل نقله.
- نسخ النتيجة بسرعة وإعادة استخدامها.

## ✨ المزايا
- 🎨 **Beautify**: تنسيق JSON بمسافات بادئة 2 أو 4.
- 🗜️ **Minify**: ضغط JSON بإزالة كل المسافات.
- ✅ **Validate**: التحقق من صحة البنية مع رسالة خطأ واضحة (السطر والعمود).
- 🌳 **Tree View**: عرض شجري قابل للطي/التوسيع.
- 📋 **Copy & Download**: نسخ النتيجة أو تنزيلها كملف `.json`.
- 📥 **Load Sample**: تحميل عينة JSON جاهزة بضغطة زر.
- 🌙 **Dark Mode**: وضع داكن مع حفظ التفضيل في `localStorage`.
- 📱 **Responsive**: تصميم متجاوب يعمل على الموبايل والديسكتوب.
- 🔢 **Stats**: عدد المفاتيح، حجم الملف، عمق التداخل.

## 🛠️ التقنيات
- **HTML5** — البنية الدلالية.
- **CSS3 + Tailwind** — تصميم حديث ومتجاوب.
- **TypeScript** (Vanilla) — منطق التنسيق والتحقق بأنواع آمنة.
- **LocalStorage API** — حفظ آخر مدخل وتفضيل الوضع الداكن.
- **Clipboard API** — نسخ النتائج.
- **Blob API** — تنزيل النتائج كملف.

## 🚀 خطوات التشغيل المحلي

1. استنسخ المستودع:
   ```bash
   git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
   cd My-Portfolio/frontend/json-formatter-app
   ```
2. افتح `index.html` مباشرة في المتصفح، أو شغّل خادم محلي:
   ```bash
   npx serve .
   ```
3. افتح `http://localhost:3000` في المتصفح.
