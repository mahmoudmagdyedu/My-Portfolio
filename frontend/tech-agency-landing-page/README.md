# 🚀 NexaTech — Tech Agency Landing Page

A sleek, modern landing page for a fictional tech agency, featuring glassmorphism design and smooth scroll animations.

## ✨ Features
- Glassmorphism UI with backdrop blur
- Gradient animated hero
- Services, Team, Testimonials sections
- Dark-themed modern design
- Fully responsive

## 🛠️ Tech Stack
- HTML5, CSS3, Tailwind CSS (CDN), JavaScript, Google Fonts (Inter)
