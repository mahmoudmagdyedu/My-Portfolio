# 🎨 PaletteForge — Color Palette Generator

> مولّد لوحات ألوان احترافي للمصممين والمطورين، يولّد توليفات متناسقة بضغطة زر مع إمكانية قفل الألوان ونسخ أكواد الـHex.

## 🎯 المشكلة
اختيار لوحة ألوان متناسقة من الصفر مهمة مستهلكة للوقت. الأدوات الموجودة كثيرها معقّد أو مدفوع، والمصمم/المطور بحاجة لأداة بسيطة تعطيه أفكاراً سريعة ومتجدّدة.

## ✨ المزايا
- 🎲 توليد لوحة من **5 ألوان عشوائية متناسقة** بضغطة زر واحدة (أو مفتاح Space).
- 🔒 **قفل الألوان** — احتفظ بالألوان اللي عجبتك وجدّد الباقي فقط.
- 📋 **نسخ بضغطة** — انقر على أي لون لنسخ كود الـHex مباشرة للحافظة.
- 💾 **تصدير اللوحة** كـ JSON أو نسخها كاملة.
- 🌓 **وضع داكن/فاتح** قابل للتبديل.
- 📱 **تصميم Responsive** يعمل على كل الأحجام.

## 🛠️ التقنيات
- HTML5 (Semantic)
- CSS3 (Custom Properties + Grid + Flexbox)
- Vanilla JavaScript (ES6+)
- Clipboard API
- LocalStorage (لحفظ آخر لوحة + التفضيلات)
