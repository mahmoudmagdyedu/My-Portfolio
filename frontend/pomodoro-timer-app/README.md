# ⏱️ Pomodoro Timer App

A clean, responsive Pomodoro productivity timer built with **TypeScript**, HTML, and CSS. Helps you stay focused using the Pomodoro Technique — 25 minutes of focused work followed by short breaks.

## 🎯 Problem

Staying focused for long periods is hard. The Pomodoro Technique breaks work into manageable intervals with regular breaks, boosting productivity and reducing burnout.

## ✨ Features

- **25-minute work sessions** with 5-minute short breaks and 15-minute long breaks
- **Visual countdown** with circular progress indicator
- **Session tracking** — counts completed pomodoros
- **Audio notification** when a session ends
- **Start / Pause / Reset** controls
- **Responsive design** — works on desktop and mobile
- **TypeScript** for type-safe state management

## 🛠️ Technologies

- HTML5
- CSS3 (Custom Properties, Flexbox, Animations)
- TypeScript
- No external dependencies

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
   cd My-Portfolio/frontend/pomodoro-timer-app
   ```
2. Open `index.html` in your browser — no build step required (uses inline compiled JS).
