# 🔗 LinkVault — Bookmark Manager App

A sleek, feature-rich bookmark manager built with **TypeScript** and **Tailwind CSS**. Organize, search, and manage your favorite links with categories, tags, and local storage persistence.

![LinkVault Preview](https://images.unsplash.com/photo-1456324504439-367cee3b3c32?w=800&q=60)

---

## 🚀 Features

- **CRUD Operations** — Add, edit, delete, and view bookmarks
- **Categories & Tags** — Organize links by custom categories and color-coded tags
- **Smart Search** — Instant search across titles, URLs, descriptions, and tags
- **Favorites** — Star important bookmarks for quick access
- **Import / Export** — Backup and restore bookmarks as JSON
- **Local Storage** — All data persists in the browser with no backend needed
- **Responsive Design** — Works beautifully on mobile, tablet, and desktop
- **Dark Mode** — Toggle between light and dark themes
- **Drag & Sort** — Reorder bookmarks within categories
- **Favicon Preview** — Auto-fetches website favicons for visual recognition

## 🛠️ Tech Stack

| Technology | Purpose |
|---|---|
| **TypeScript** | Type-safe logic, interfaces, and enums |

| **HTML5** | Semantic markup and accessibility |

## ⚡ Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
   cd My-Portfolio/frontend/bookmark-manager-app
   ```
2. Open `index.html` in your browser — no build tools required!
3. (Optional) To edit TypeScript, compile with:
   ```bash
   npx tsc app.ts --target ES2020 --outFile app.js
   ```
