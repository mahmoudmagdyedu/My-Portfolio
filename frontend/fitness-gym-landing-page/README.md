# 💪 FitZone — Fitness & Gym Landing Page

صفحة هبوط احترافية لنادي رياضي تتضمن حاسبة BMI تفاعلية، خطط اشتراك، جدول حصص، وقسم شهادات العملاء.

## ✨ المزايا
- تصميم حديث بتدرجات Dark/Neon
- حاسبة BMI تفاعلية بـ JavaScript
- خطط اشتراك مع تمييز الخطة المميزة
- جدول الحصص الأسبوعي
- قسم شهادات وآراء الأعضاء
- متجاوب بالكامل (Mobile-first)

## 🛠️ التقنيات
- HTML5, CSS3, Tailwind CSS (CDN), JavaScript
