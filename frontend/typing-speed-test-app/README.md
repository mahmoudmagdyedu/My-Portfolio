# Typing Speed Test App

تطبيق ويب تفاعلي لاختبار سرعة الكتابة يعرض نصًا عشوائيًا، ويقيس **WPM** (كلمة في الدقيقة)، **الدقة %**، وعدد الأخطاء، خلال مؤقت قابل للاختيار (15 / 30 / 60 ثانية).

## 🔴 المشكلة
المطوّرون والطلاب يحتاجون أداة بسيطة وسريعة لقياس وتحسين سرعة الكتابة بدون تسجيل أو إعلانات ثقيلة.

## ✨ المزايا
- مؤقت قابل للاختيار: 15 / 30 / 60 ثانية.
- حساب فوري لـ WPM والدقة وعدد الأخطاء.
- تلوين الحرف الصحيح/الخاطئ أثناء الكتابة.
- إعادة المحاولة بضغطة واحدة.
- بنك نصوص عشوائي داخلي (قابل للتوسيع).
- واجهة Responsive بلمسة Dark-mode.

## 🛠️ التقنيات
- HTML5
- CSS3 (Flexbox + Custom Properties)
- JavaScript (Vanilla, ES2020)

## ▶️ التشغيل المحلي
```bash
# من جذر المستودع
cd frontend/typing-speed-test-app
# افتح index.html مباشرة في المتصفح
# أو استخدم Live Server من VS Code
```
