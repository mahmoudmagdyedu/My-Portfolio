## 🔍 المشكلة

نحتاج أحيانًا لتتبّع الأحداث المهمة — مواعيد تسليم، أعياد ميلاد، أحداث مهنية — بطريقة بصرية واضحة ومحفّزة. التطبيقات الموجودة إما معقّدة أو تتطلب تسجيل.

## ✨ المزايا

- ➕ إنشاء عدّادات متعددة لأحداث مختلفة
- ⏱️ تحديث لحظي (أيام، ساعات، دقائق، ثوانٍ)
- 🎨 أيقونات وألوان مخصصة لكل حدث
- 🗑️ حذف وتعديل الأحداث
- 💾 حفظ تلقائي في LocalStorage
- 🌙 وضع داكن / فاتح
- 📱 متجاوب بالكامل (Responsive)
- 🔔 تنبيه عند وصول العد لصفر

## 🛠️ التقنيات

| التقنية | الاستخدام |
|---|---|
| HTML5 | البنية الأساسية |
| TypeScript | منطق التطبيق وإدارة الحالة |
| Tailwind CSS | التنسيق والتصميم المتجاوب |
| LocalStorage | حفظ البيانات محليًا |

## 🚀 التشغيل المحلي

```bash
# 1. استنسخ الـ Monorepo
git clone https://github.com/mahmoudmagdyedu/My-Portfolio.git
cd My-Portfolio/frontend/event-countdown-app

# 2. افتح في المتصفح
# يمكنك استخدام Live Server أو فتح index.html مباشرة
npx serve .
```
