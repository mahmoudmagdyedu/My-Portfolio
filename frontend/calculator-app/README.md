# CalcPro — Calculator App

> آلة حاسبة احترافية بمظهر حديث، تدعم العمليات القياسية والعلمية، مع سجل عمليات وحفظ محلي ووضع داكن.

## 🧩 المشكلة
المستخدم يحتاج إلى آلة حاسبة سريعة وموثوقة على الويب — تتجاوز الحساب الأساسي لتشمل العمليات العلمية الشائعة (sin/cos/log/√/^)، مع إمكانية مراجعة النتائج السابقة دون فقدها عند تحديث الصفحة.

## ✨ المزايا
- وضعان: **Standard** و **Scientific** (تبديل بضغطة).
- العمليات الأساسية: ‎+ − × ÷‎، النسبة المئوية، تغيير الإشارة.
- عمليات علمية: ‎sin, cos, tan, log, ln, √, x², x^y, π, e, !‎.
- **سجل العمليات (History)** مع حفظ محلي عبر `localStorage` وإعادة استخدام أي نتيجة سابقة.
- دعم لوحة المفاتيح الكامل (أرقام، عمليات، Enter، Backspace، Esc).
- معالجة أخطاء واضحة (قسمة على صفر، صياغة غير صحيحة).
- **الوضع الداكن (Dark Mode)** مع حفظ التفضيل.
- تصميم Responsive يعمل على الموبايل والديسكتوب.

## 🛠️ التقنيات المستخدمة
- HTML5 سيمانتيك
- CSS3 (CSS Variables + Flex/Grid)
- JavaScript (ES2020) — بدون أي مكتبات خارجية
- LocalStorage API
