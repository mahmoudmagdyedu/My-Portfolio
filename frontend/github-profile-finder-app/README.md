# GitHubLens — GitHub Profile Finder App

> تطبيق ويب يتيح البحث عن أي مستخدم GitHub وعرض ملفه الشخصي ومستودعاته الأكثر شهرة من خلال GitHub REST API، مع واجهة Responsive ووضع داكن.

## 🧩 المشكلة
الحاجة المتكرّرة لاستعراض ملفات مطوّرين على GitHub بدون فتح الموقع — نريد أداة سريعة تعطي لمحة عن المستخدم (صورته، نبذته، إحصاءاته، أهم مستودعاته).

## ✨ المزايا
- 🔍 بحث فوري عن أي مستخدم باسم المستخدم.
- 👤 عرض الصورة، الاسم، النبذة، الموقع، عدد المتابعين/المتابَعين/المستودعات.
- 📦 جلب أهم 6 مستودعات وفرزها حسب عدد النجوم.
- 🌗 وضع داكن/فاتح مع حفظ الإعداد محلياً.
- ⚠️ معالجة أخطاء واضحة (مستخدم غير موجود / مشكلة شبكة / تجاوز حد المعدل).
- ⌨️ دعم كامل للوحة المفاتيح وتجربة Responsive.

## 🛠️ التقنيات
- HTML5 / CSS3
- JavaScript (ES2020+) بأسلوب TypeScript-Inspired
- Tailwind CSS (CDN)
- GitHub REST API v3
- LocalStorage (حفظ الوضع الداكن وآخر بحث)

## ▶️ التشغيل المحلي
```bash
# من جذر الـ Monorepo
npm start
# ثم افتح في المتصفح:
http://localhost:3000/frontend/github-profile-finder-app/
```
أو افتح `index.html` مباشرة في المتصفح.
